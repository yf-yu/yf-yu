## 🔥 免費工具入口  
### 🧠 判斷與決策工具  

這組工具從資訊不對稱、恐懼行銷及高壓決策等生活情境出發，將抽象問題拆解成可逐步檢查的項目。  

#### **恐懼拆解表**  
當有人告訴你「不處理會出事」「現在不做就來不及」時，透過八個步驟區分可確認的事實、對方的解釋、預測後果、時間壓力與建議方案。  

- 依填寫內容標記常見高壓話術訊號
- 區分可驗證與尚無法確認的主張
- 依不同情境提供後續確認方向與求助資訊  
- 產生可列印或另存 PDF 的個人整理報告

👉 [免費使用｜恐懼拆解表](https://hengzhenfang.pages.dev/tools/fear-unpack/?utm_source=github&utm_medium=portfolio&utm_campaign=free_tools&utm_content=fear_unpack)

#### **決策拆解器**

針對正在考慮的購買、付款或其他重大決定，透過 **6** 個步驟檢視問題定義、解決方案、可能後果、替代選項及個人決策動機   

- 檢視問題提出者、解方提供者與效果判定方式
- 整理費用負擔、可核對的結果及其他選擇
- 依填寫內容提供決策風險提示
- 產生可列印或另存 PDF 的決策整理單

## 🧩 作品規劃與實作方式

這些專案主要從生活中的實際問題與資訊需求出發，透過自主研究、流程規劃及反覆測試，逐步完成可操作的工具  

**主要投入的工作包括：**

1. **問題釐清：** 確認使用情境、資訊需求與工具目標。
2. **資料研究：** 蒐集相關資訊，整理內容分類及資料來源。
3. **架構規劃：** 拆解功能需求，規劃操作流程與資訊呈現方式。
4. **AI 輔助實作：** 運用 AI 工具協助產生及調整程式碼。
5. **測試與修正：** 檢查功能與輸出結果，反覆調整操作流程。
6. **成果整合：** 整理工具說明、使用入口及相關內容。

作品著重於跨領域學習、邏輯拆解、資訊組織、流程規劃與實際成果整合。
